# 2-4 cloud

운영 주소: [2-4.cloud](https://2-4.cloud) · 공개 소스: [GitHub](https://github.com/fakeminjun7321/2-4cloud)

자료실과 캘린더 두 탭으로 구성된 학급 사이트입니다. 자료는 과목과 담당 선생님별로 분류하며, 사진·PDF·시험범위 설명을 등록할 수 있습니다. 일정은 날짜, 유형, 과목, 선생님과 설명을 저장합니다. 학생은 비밀번호 없이 열람하고, 등록·수정·삭제는 관리자 로그인 후 가능합니다.

현재 사진 자료는 영어 이계화T의 `1지문` 22장과 `2지문` 7장입니다. 2026학년도 2학기 학사일정표의 날짜별 항목 39개는 초안임을 알 수 있도록 `(안)`을 붙여 캘린더에 저장했습니다. 파일은 Cloudflare R2, 과목·자료·일정·세션 정보는 Cloudflare D1에 보관합니다. `worker/schema.sql`에 지정된 과목 12개와 선생님 20명의 초기 목록이 있습니다.

학생은 사이트를 홈 화면에 추가해 PWA로 사용할 수 있고, 직접 알림을 허용한 기기에 한해 시험·수행평가·제출 일정의 7일 전·1일 전·당일 알림을 받습니다. 서버는 매일 한국시간 07:00에 그날의 알림을 한 번 묶어 무음으로 발송합니다. 학사일정표 `(안)`에서 가져온 항목의 알림은 꺼 두었습니다. NEIS 급식은 운영 API 키가 설정된 경우 같은 알림에 포함됩니다. 브라우저와 운영체제의 권한·전달 정책에 따라 실제 수신 시각은 달라질 수 있습니다.

## 배포

Node.js 20.19 이상과 Cloudflare 계정에 로그인한 Wrangler가 필요합니다.

```sh
npm ci
npm run build
npx wrangler deploy
```

현재 `wrangler.jsonc`는 전용 D1 데이터베이스 `class-2-4-db`, R2 버킷 `class-2-4-files`, 도메인 `2-4.cloud`를 가리킵니다. 새 데이터베이스를 만들 때만 `worker/schema.sql`을 적용하세요. 운영 데이터가 들어 있는 기존 D1/R2는 초기화하지 마세요.

관리 비밀번호는 브라우저 코드에 들어 있지 않습니다. Worker 비밀값 `ADMIN_PASSWORD_SHA256`에 비밀번호의 UTF-8 SHA-256 해시가 저장되어 있으며, 로그인 시도는 D1에서 제한합니다. 비밀번호를 바꾸려면 해시를 다시 설정하고 `sessions` 테이블의 기존 세션을 폐기해야 합니다. Web Push에는 `VAPID_PUBLIC_KEY`와 `VAPID_PRIVATE_JWK` 비밀값이 필요합니다. 급식 발송에는 NEIS 개발자 포털에서 발급한 `NEIS_API_KEY`가 필요하며, 키가 없어도 일정 알림은 동작합니다. 비밀값은 소스에 포함하지 않습니다. 세부 계약은 `worker/README.md`에 있습니다.

## 로컬 확인

```sh
npm ci
npm run build
npx wrangler d1 execute class-2-4-db --local --file=worker/schema.sql
npx wrangler dev --local --port 8787
```

관리자 로그인과 푸시 구독을 로컬에서 시험하려면 `.dev.vars`에 `ADMIN_PASSWORD_SHA256`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_JWK`를 설정해야 합니다. 이 파일은 Git에 포함되지 않습니다. 개발 서버는 Cloudflare의 로컬 D1/R2를 사용하므로 운영 사진과 일정에 영향을 주지 않습니다.

## 현재 한계

- 사진과 PDF 파일은 한 파일당 20MB, 한 번에 24개까지 올릴 수 있습니다.
- 조회에는 학생 로그인이 없습니다. 주소를 아는 사람은 자료를 볼 수 있으므로 반 안에서 공유 범위를 정해 사용하세요.
- 푸시 알림은 Cloudflare Workers Free 한도에 맞춰 최대 45개 기기, 공유 IP당 하루 신규 25개 기기로 제한합니다. 한 학생의 여러 기기는 각각 한 자리를 차지합니다.
- 구글 캘린더·노션과의 자동 동기화는 연결하지 않았습니다.
